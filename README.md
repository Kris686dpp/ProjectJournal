# ProjectJournal

A digital diary for Android devices.

## Features
- Write text based journal entries and label them by their mood.
- Creating entries is done on the CreateScreen.
- Entries are saved into a local Room database.
- Entries are displayed on the homescreen as a list sorted by their date.

## Tech Stack
- Kotlin
- Jetpack Compose 
- Room (with KSP)
- ViewModel and StateFlow

## Planned
- Edit and delete entries
- Sort entries by mood
- Set custom time when creating entries
